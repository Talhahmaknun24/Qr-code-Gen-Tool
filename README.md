# QR Code Generator Pro

একটি সম্পূর্ণ ফ্রি, সিঙ্গেল-ফাইল QR কোড জেনারেটর। `index.html` ফাইলটি ব্রাউজারে খুললেই চলবে — কোনো সার্ভার বা ইনস্টলেশন লাগবে না। সব কাজ ব্রাউজারেই হয়, কোনো তথ্য বাইরে পাঠানো হয় না।

## ফিচারসমূহ

- **৬ ধরনের QR:** টেক্সট/URL, WiFi (SSID + পাসওয়ার্ড + নিরাপত্তার ধরন + হিডেন নেটওয়ার্ক), ফোন (`tel:`), SMS (`SMSTO:`), ইমেইল (`mailto:` বিষয় ও মেসেজসহ), vCard (নাম, ফোন, ইমেইল, প্রতিষ্ঠান, ওয়েবসাইট, ঠিকানা)
- **কাস্টমাইজেশন:** QR-এর রং ও ব্যাকগ্রাউন্ড রং বেছে নেওয়া, সাইজ ২৫৬–১০২৪ px, Error Correction লেভেল (L/M/Q/H)
- **লোগো:** নিজের ছবি/লোগো আপলোড করলে QR-এর ঠিক মাঝখানে বসে যায় (সাদা প্যাডিংসহ); লোগো দিলে Error Correction স্বয়ংক্রিয়ভাবে H হয়
- **লাইভ প্রিভিউ:** টাইপ করার সাথে সাথে QR আপডেট হয়, আর নিচে দেখা যায় আসলে কী এনকোড হচ্ছে
- **ডাউনলোড ও কপি:** PNG ডাউনলোড বাটন এবং ক্লিপবোর্ডে ছবি কপি করার বাটন
